# Skills

Personal agent skills maintained in this repository.

## Available Skills

| Skill | Purpose |
| --- | --- |
| [`diagram`](skills/diagram/SKILL.md) | Publish Mermaid diagrams to `diagram.bhk.dev` and return permanent shareable URLs. |

## Conventions

- Each skill lives in `skills/<name>/SKILL.md`.
- Keep instructions focused on the workflow an agent needs to execute.
- Document external service behavior, limits, and security constraints next to the relevant skill.
- Treat skill changes as documentation changes: verify commands, endpoints, and examples before publishing.
